# Chamberly Web

The frontend repository for Chamberly, a research-first healthcare SaaS concept for Bangladesh.

## Project status

**Current phase: project foundation and documentation only.** No application code has been authorized or implemented in this repository.

## Planned frontend

- Next.js App Router
- TypeScript

These are proposed technologies, not an implemented stack.

## Working principles

- Keep market-validation research separate from product implementation.
- Document architecture and development standards before implementation.
- Use synthetic data during early development; do not add real patient or other sensitive health information.
- Treat tenant isolation and server-side authorization as mandatory design concerns before handling any customer data.
- Do not add application code, dependencies, deployment configuration, or integrations without explicit approval.

## Related repositories

- `chamberly-api` — planned Spring Boot API repository; not assumed to exist yet.
- `chamberly-docs` — optional project documentation repository; decision pending.

## Naming

Chamberly is a provisional project name. Domain, trademark, and company-name checks remain outstanding.
